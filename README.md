# Camkeys

Браузерный прототип клавиатуры, управляемой движениями пальца перед камерой. Распознавание работает локально: MediaPipe отслеживает руки, словарь сопоставляет траекторию со словами, TensorFlow.js позволяет обучать персональную модель.

## Возможности

- Полупрозрачная клавиатура с перспективой 45°. Круглая кнопка RU/EN в правом нижнем углу окна камеры переключает язык по удержанию указательного пальца на ней 2 секунды (или по клику). Кольцо показывает прогресс; повторное переключение требует убрать палец. Во время удержания буквы, взмахи и автоматическая вставка приостановлены. Выбор сохраняется; автоматического переключения нет.
- Калибровка по буквам: удержание каждой цели в течение 2 секунд.
- Один активный палец на время слова, сохранение траектории при кратких сбоях.
- Относительная оценка глубины по ладони и исключение дальних координат из ввода.
- Вероятные префиксы вместо списка всех пересечённых клавиш; частотные словари: 48 249 русских и 46 763 английских слов и форм.
- Автовставка через 1.5 секунды после распознавания без продолжения движения; вправо — подтвердить, влево — отменить текущую попытку или последнюю вставку.
- Цикл плашки: буквы → слово → вставка → затухание за 2 секунды → пустое поле.
- Демонстрация и ввод мышью без камеры, обучение на собственных размеченных траекториях.

## Запуск

Нужен Node.js 22.12+; разработка и проверки выполнялись на Node.js 24.

```sh
git clone https://github.com/mb-mal/camkeys.git
cd camkeys
npm ci
npm run assets
npm run dev -- --port 5173
```

Откройте http://127.0.0.1:5173/. Для остановки сервера нажмите Ctrl+C.

`npm run assets` копирует WASM из установленного пакета и скачивает официальную модель Hand Landmarker с проверкой SHA-256. Модель и скопированные библиотеки не хранятся в репозитории. Установка зависимостей и первоначальная подготовка модели требуют интернета; дальнейший ввод выполняется локально.

Для камеры разрешите доступ браузеру, примите рабочее положение ладони за 1× и пройдите буквенную калибровку. Камера доступна на localhost или HTTPS. Для проверки без камеры проведите мышью по клавиатуре либо включите демонстрацию.

## Проверки и сборка

```sh
npm test
npm run build
npm run preview -- --port 4173
```

Браузерные проверки требуют запущенного dev server на порту 5173 и установленного Microsoft Edge:

```sh
npm run test:browser
npm run test:calibration-rendered
npm run test:dwell
npm run test:layout
node tests/english.browser.mjs
node tests/word-fade.browser.mjs
```

Запускайте проверки с видеопотоками по очереди. Они используют изолированные профили, синтетическое видео и тестовые движения; это не проверка физической камеры пользователя.

Сценарии `replay:live`, `test:live`, `scripts/replay-*.mjs` и отдельные браузерные регрессии воспроизводят личные записи из `test-results/`. Эти записи не публикуются и не нужны для запуска приложения или `npm test`. Их ожидаемые слова используются только в проверках, а не в рабочем декодере.

## Данные и ограничения

Видео не записывается и не отправляется на сервер. Текст, калибровка и обучающие примеры сохраняются в локальном хранилище браузера. Диагностическая запись включается отдельной кнопкой и содержит координаты рук, оценки глубины и события распознавания; экспортируйте её только при необходимости.

Это исследовательский прототип. Глубина оценивается относительно размера ладони, без сантиметров. Поворот кисти, перекрытие рук и выход из кадра ухудшают оценку. Восстановление канала команд после потери ID ограничено близкой одиночной кистью и коротким интервалом; неоднозначный трек не считается надёжной командой.

Словари частотные, не нормативные: встречаются имена, формы слов и корпусный шум. Английский распознаёт также стандартные сокращения: путь по буквам `dont` может возвращать `don't`. Словарь и анализ префиксов следуют выбранному вручную языку. При недоступности одного корпуса явно включается его ограниченный резерв; второй язык продолжает работать. Вероятности промежуточных гипотез не являются измеренной точностью; автоматический ввод может ошибаться. Персональная Conv1D изначально не обучена, до обучения используется геометрия и словарь.

## Структура

- `src/` — геометрия, калибровка, ввод, декодер, интерфейс и обучение.
- `public/tracking.worker.js` — трекер рук вне основного потока.
- `public/dictionaries/` — русский словарь и атрибуция.
- `public/licenses/` — лицензионные тексты сторонних компонентов.
- `scripts/assets.mjs` — воспроизводимая подготовка модели и WASM.
- `tests/` — модульные и браузерные проверки.
